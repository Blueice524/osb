# 靜讀

繁體中文的每日查經與讀經日記網站，融合「每日經文與查經參考」與「Bible Journal — Shared」的方法。朋友打開相同網址可使用同一套介面；日記各自保存在自己的瀏覽器。

## 已實作

- 第二分頁「個人讀經進度」提供新舊約 66 卷、1,189 章；選章自動保留當日進度，右側日記與每日靈糧各自記錄，支援重載、搜尋及備份。
- 7 篇原創精選摘要、背景、解釋、兩項反思與禱告引導，按使用者當地日期輪替，可自行選擇。
- YouVersion 繁體新譯本完整經文連結與讚美之泉官方頻道連結。
- 兩個讀經分頁都提供「詢問」：複製目前經文與問題、開啟 ChatGPT（有分享網址時則開啟原 GPT），回答可手動貼回保存，支援追問、搜尋、備份。
- 觀察、理解、心得、行動、禱告、問題、標籤分開記錄；不會替使用者填寫個人反思。
- `mark 內容`、`今天結束` / `over for today`、`搜尋 關鍵字`。其他指令存為待查問題。
- 筆記搜尋、完成天數、連續天數、本月完成天數、JSON 匯出／匯入。
- 分享連結只含經文代號，不包含筆記。手機與桌面皆可使用。

## 邊界與隱私

這是無後端、免登入的版本。個人進度的查經引導是通用方法，不是 1,189 章的專屬解說。沒有直接呼叫 ChatGPT 外掛 API 或私人知識庫；「詢問」會開啟 ChatGPT，未提供 GPT 分享網址時需使用者自行選用外掛；需貼上問題送出並手動貼回回答，不會自動擷取 GPT 回覆。沒有跨裝置同步、365 篇不重複計畫，或 bible.com 每日進度同步。內容是人工編寫的經文摘要，不是逐字引用繁體新譯本全文。詩歌連結指向官方頻道，不是當日查核的指定曲目。

筆記儲存在目前來源的 localStorage。同一裝置同一瀏覽器使用者可讀到同一份筆記；不同來源（如開發站與正式站）不會共用。清除瀏覽器資料、無痕視窗結束、換手機都可能失去存取，請定期匯出。匯出檔案含私人筆記；匯入保留既有同日同經文的筆記。不得把匯出檔提交到 GitHub。

## 本機開發

需要 Node.js 22.12+ 或 24。使用現有 checkout，不需另建 worktree。

```bash
cd /workspace/osb
npm ci --cache /tmp/osb-npm-cache
npm run dev
```

```bash
npm run build
npm test
```

瀏覽器測試預設使用 `/usr/bin/chromium`，其他路徑用 `CHROMIUM_PATH` 指定。測試覆蓋保存／重載、Mark、完成、搜尋、不同瀏覽器資料隔離、分享不含筆記、備份匯入匯出、無效備份與手機排版。

## 分享與部署

`npm run build` 產生 `dist/`，可放在任何靜態網站服務。使用相對資源路徑，支援 GitHub Pages 的 `/osb/` 子路徑。

GitHub Pages：在儲存庫 **Settings → Pages → Build and deployment** 選擇 **GitHub Actions**，再到 **Actions → Deploy 靜讀 to GitHub Pages → Run workflow** 手動發布；推送更新至 `main` 也會自動發布。此流程不會自動上傳任何讀經日記。部署成功後以 workflow 顯示的實際網址為準。GitHub Pages 是否可用取決於儲存庫可見性及帳號方案。

網站程式碼完成並不表示已經發布。新增登入、雲端同步或 AI 解經，需要另行配置後端、個人資料存取控制與伺服器端金鑰；不要把 AI 金鑰放入靜態網頁。

## 原 GPT 對話設定

在 `public/gpt-config.json` 的 `gpt_url` 填入 GPT 發布者提供的 `https://chatgpt.com/g/...` 公開網址，再建置發布。`plugin://...` 是 ChatGPT 內的外掛識別，不是瀏覽器可分享的 GPT 網址，不可用來替代。連結未設定或格式不符時，「詢問」會開啟 `https://chatgpt.com/`，頁面清楚要求使用者自行選用原外掛。這不是自動串接，不保證每個朋友的帳號都有該外掛；請勿將此模式描述為直接開啟指定 GPT。

「詢問」會先保存問題，複製目前經文、該問題及本段最近十則已貼回的討論，並開啟 ChatGPT（有有效分享網址時則開啟該 GPT）。若自動複製或彈出視窗被阻擋，頁面提供可手動複製的文字與ChatGPT 連結。使用者在 GPT 貼上送出，自行選用外掛，再把回答貼回網站按「儲存回覆」。其他心得、禱告不會複製。所有探討紀錄跟隨日期和經文保留，會納入搜尋與匯出／匯入；個人與每日頁面互相分開。ChatGPT 端的登入、分享權限與方案限制仍由 GPT 發布者和 ChatGPT 管理。

此版本沒有後端、AI 金鑰，也不聲稱自動取得原 GPT 回覆。公開網址須由擁有者提供，不能從外掛 ID 推測。
