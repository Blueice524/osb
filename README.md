# PB

繁體中文的每日查經與讀經日記網站，融合「每日經文與查經參考」與「Bible Journal — Shared」的方法。朋友打開相同網址可使用同一套介面；日記各自保存在自己的瀏覽器。

## 已實作

- 7 篇原創精選摘要、背景、解釋、兩項反思與禱告引導，按使用者當地日期輪替，可自行選擇。
- YouVersion 繁體新譯本完整經文連結與讚美之泉官方頻道連結。
- 觀察、理解、心得、行動、禱告、問題、標籤分開記錄；不會替使用者填寫個人反思。
- `mark 內容`、`今天結束` / `over for today`、`搜尋 關鍵字`。其他指令存為待查問題。
- 筆記搜尋、完成天數、連續天數、本月完成天數、JSON 匯出／匯入。
- 分享連結只含經文代號，不包含筆記。手機與桌面皆可使用。

## 邊界與隱私

這是無後端、免登入的第一版。沒有直接呼叫 ChatGPT 外掛、私人知識庫或 AI 服務；沒有即時 AI 問答、跨裝置同步、365 篇不重複計畫，或 bible.com 每日進度同步。內容是人工編寫的經文摘要，不是逐字引用繁體新譯本全文。詩歌連結指向官方頻道，不是當日查核的指定曲目。

筆記儲存在目前來源的 localStorage。同一裝置同一瀏覽器使用者可讀到同一份筆記；不同來源（如開發站與正式站）不會共用。清除瀏覽器資料、無痕視窗結束、換手機都可能失去存取，請定期匯出。匯出檔案含私人筆記；匯入保留既有同日同經文的筆記。不得把匯出檔提交到 GitHub。

## 本機開發

需要 Node.js 22.12+ 或 24。使用現有 checkout，不需另建 worktree。

```bash
cd /workspace/osb
npm ci --cache /tmp/osb-npm-cache
npm run dev
```

```bash
npm run build
npm test
```

瀏覽器測試預設使用 `/usr/bin/chromium`，其他路徑用 `CHROMIUM_PATH` 指定。測試覆蓋保存／重載、Mark、完成、搜尋、不同瀏覽器資料隔離、分享不含筆記、備份匯入匯出、無效備份與手機排版。

## 分享與部署

`npm run build` 產生 `dist/`，可放在任何靜態網站服務。使用相對資源路徑，支援 GitHub Pages 的 `/osb/` 子路徑。

GitHub Pages：在儲存庫 **Settings → Pages → Build and deployment** 選擇 **GitHub Actions**，再到 **Actions → Deploy PB to GitHub Pages → Run workflow** 手動發布；推送更新至 `main` 也會自動發布。此流程不會自動上傳任何讀經日記。部署成功後以 workflow 顯示的實際網址為準。GitHub Pages 是否可用取決於儲存庫可見性及帳號方案。

網站程式碼完成並不表示已經發布。新增登入、雲端同步或 AI 解經，需要另行配置後端、個人資料存取控制與伺服器端金鑰；不要把 AI 金鑰放入靜態網頁。
